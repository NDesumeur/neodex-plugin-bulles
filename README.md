# Bulles

Vise et tire des bulles : trois de la même couleur éclatent, et celles qui ne tiennent plus à rien tombent.

Tire des bulles vers le plafond. Trois bulles (ou plus) de la même couleur qui se touchent éclatent ; tout ce qui ne tient plus au plafond tombe. La partie s'arrête quand les bulles touchent la ligne du bas.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Bulles → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
